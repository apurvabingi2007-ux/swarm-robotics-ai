# Leaderless Vision-Guided Swarm Robots with Individual Intelligence

A team project exploring coordination between multiple robots using computer vision and AI.

- **Robots:** ESP32-based robots
- **Computer vision:** OpenCV and ArUco markers for robot tracking
- **AI:** Explored GPT-4o for vision-based decision-making

The project explores how multiple robots can work towards a common goal without relying on a central leader.
