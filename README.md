# Leaderless Vision-Guided Swarm Robots with Individual Intelligence

## About the Project
This team project explores how multiple robots can coordinate and work towards a common goal without relying on a central leader. It combines robotics, computer vision, and AI-assisted decision-making.

## Technologies
- **Python** — project logic and integration
- **OpenCV** — computer vision
- **ArUco markers** — identifying and tracking robot positions
- **ESP32** — robot hardware and control
- **GPT-4o** — explored for AI-assisted decision-making using visual information

## How It Works
An overhead camera provides visual information about the robots. Computer vision techniques are used to detect and track their positions. The project explores how this information can support decisions about robot movement and coordination.

## Project Goals
- Explore vision-guided robot tracking.
- Understand coordination between multiple robots.
- Investigate AI-assisted decision-making in a physical robotics setup.
- Learn about integrating software, computer vision, and hardware.

## What I Learned
This project helped me explore computer vision, robot control, and the challenges of connecting software decisions with real-world hardware.
